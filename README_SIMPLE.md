# 간단 스크래핑 가이드 🎯

**사이트명과 기종명만 입력하면 자동으로 스크래핑하고 슬랙으로 전송합니다!**

## 🚀 빠른 시작

### 1. 환경변수 설정 (.env)

```bash
# LLM API 키 (필수)
GEMINI_API_KEY=your_gemini_api_key_here

# 슬랙 웹훅 URL (필수 - 결과 전송용)
SLACK_WEBHOOK_URL=https://hooks.slack.com/services/YOUR/WEBHOOK/URL
```

### 2. 실행 방법

#### 방법 1: Makefile 사용 (가장 간단!)

```bash
# 단일 사이트, 단일 기종
make scrape-simple SITES='하이폰' MODELS='갤럭시S25'

# 여러 사이트, 여러 기종
make scrape-simple SITES='하이폰,딜리버리폰' MODELS='갤럭시S25,아이폰17'

# 예제 실행
make scrape-simple-example
```

#### 방법 2: 직접 실행

```bash
# 단일 사이트, 단일 기종
uv run python scrape_simple.py --sites 하이폰 --models 갤럭시S25

# 여러 사이트, 여러 기종
uv run python scrape_simple.py \
  --sites 하이폰,딜리버리폰 \
  --models 갤럭시S25,아이폰17
```

#### 방법 3: 설정 파일 사용

1. `my_config.json` 파일 생성:

```json
{
  "sites": ["하이폰", "딜리버리폰"],
  "models": ["갤럭시S25", "아이폰17"]
}
```

2. 실행:

```bash
# Makefile 사용
make scrape-simple-config CONFIG=my_config.json

# 직접 실행
uv run python scrape_simple.py --config my_config.json
```

## 🎯 기종명 입력 팁

### 자동 타입 판별

- **갤럭시S25** → 자동으로 "삼성" 타입으로 판별
- **아이폰17** → 자동으로 "아이폰" 타입으로 판별
- **갤럭시S25플러스** → "삼성" 타입
- **갤럭시폴드7** → "삼성" 타입

### 여러 기종 동시 검색

```bash
--models "갤럭시S25,갤럭시S25플러스,아이폰17"
```

## 📊 실행 예시

### 예시 1: 하이폰에서 갤럭시S25만

```bash
make scrape-simple SITES='하이폰' MODELS='갤럭시S25'
```

**결과:**
- 하이폰 삼성 리스트에서 갤럭시S25 찾기
- 상세 페이지에서 모든 정책 추출
- 슬랙으로 정책 데이터 전송

### 예시 2: 여러 사이트에서 여러 기종

```bash
make scrape-simple SITES='하이폰,딜리버리폰' MODELS='갤럭시S25,아이폰17'
```

**결과:**
- 하이폰 → 갤럭시S25, 아이폰17
- 딜리버리폰 → 갤럭시S25, 아이폰17
- 총 4개 작업 수행
- 각각 슬랙으로 전송

### 예시 3: 설정 파일로 배치 처리

```json
{
  "sites": ["하이폰", "딜리버리폰", "성지폰"],
  "models": ["갤럭시S25", "갤럭시S25플러스", "아이폰17"]
}
```

```bash
make scrape-simple-config CONFIG=my_config.json
```

**결과:**
- 3개 사이트 × 3개 기종 = 9개 작업
- 각 작업 완료 시 슬랙 알림
- 전체 요약도 슬랙으로 전송

## ⚙️ 옵션

```bash
# 브라우저 표시 (디버깅용)
--no-headless

# 슬랙 알림 비활성화
--no-slack
```

## 💡 사용 팁

1. **처음 사용 시**: `--no-slack` 옵션으로 테스트
2. **배치 작업**: 설정 파일 사용 권장
3. **디버깅**: `--no-headless`로 브라우저 확인
4. **슬랙 채널**: 각 제품별로 개별 알림 + 전체 요약 전송
